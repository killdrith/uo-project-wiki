# UO project wiki

Live wiki: https://killdrith.github.io/uo-project-wiki/

19 searchable pages from the September 28, 2026 handoff, preserving preferences, recommendations, and exploration.

## Editing

Edit docs/content/*.txt and run python build_wiki.py (Python 3, standard library only). Commit regenerated files to main; GitHub Pages deploys from /docs. Layout and search are in docs/style.css and docs/search.js. handoff-public.txt preserves the supplied handoff with its local Windows export path removed.

This is a public static wiki; edits use repository files and pull requests.
