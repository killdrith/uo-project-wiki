Dane Axe — isolated War Axe test

The test client replaces War Axe equipment animation 644 with our saved-grip axe. Original backpack and paperdoll art is retained. These previews were decoded from the installed animation file and overlaid on the original UO male, with the matching gray horse in mounted panels.

  1. Start your existing Subversive server if stopped: Start Subversive Server.cmd (local launcher).
  2. Run Launch Axe Test.cmd (local launcher), then log in with your owner account and male human character.
  3. Use [add WarAxe to create it.
  4. Use [set Animation Slash1H, target the axe; then [set Hue 0, target it again. Equip it.

The Animation override is required: the stock War Axe requests Bash1H, while our fitted attack uses Slash1H. This changes only your targeted test item.

Male human test, all eight directions: 17 on-foot and five mounted actions are installed. Mounted previews include the original gray horse (body 226). Female and other bodies have not been fitted. MUL conversion uses binary transparency (alpha threshold 128) and RGB555 colors. No live gameplay test has been performed yet.
